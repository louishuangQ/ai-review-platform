# 人工审核、接入与周期结果

## 页面入口及代码

- 智能审核 → 人工复核节点 / 人工复核与打分：components/ManualReviewPanel.tsx。
- 系统管理 → 服务地址与端口 / 飞书知识库接入 / 定期增量审核计划：components/ConnectionSettings.tsx。
- 审核报告 → 时间段审核总结果：components/PeriodResults.tsx。
- adapters/operations.ts 为适配边界；mocks/operations.ts 是明确的演示策略、批次及本地配置存储。正式评分需移交人工服务，不能以网页预览作为裁决。

## 已实现与限制

人工页可逐项确认、修正或要求重写，录入五维评分及依据，导出标记 MOCK_DRAFT 的草稿。初审数据不变，已终审只读。无自校验结果时禁用。草稿不提交人工 API、不修改文档状态、不写正式审计。刷新会清空未导出人工草稿。

服务默认端口来自本地 Compose，填写仅保存配置，不改变监听端口或实时 HTTP adapter。无真实连接探测；不伪造通过。知识库接入服务未部署，无默认端口。
配置存入当前浏览器 localStorage；不存真实凭证，仅接受 env:NAME 引用。请使用演示值，不填写公司机密。计划也只保存草稿，不创建后台任务，关闭页面后不会执行。

批次为 2026-09-07 / 09-08 脱敏样本。时间范围以 Asia/Shanghai 的启动日期过滤，结束日包含在内。不同 AI 阶段计数重叠，不能相加；关联文档表是当前快照，不冒充历史终审结果。此页可以包含未完成任务，最终报告库仍只收录人工确认结果。
